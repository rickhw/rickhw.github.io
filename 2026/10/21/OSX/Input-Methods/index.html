macOS 的正體中文輸入法

最近看到不少 正體中文 注音輸入法 for macOS，整理一下狀況 (同步在 Thread)， 不算測試報告 ，只是個人使用的簡單紀錄。

目前蒐集到的輸入法

標記 ✅ 是我個人已經有在試用的，其他網友推薦的有空在陸續使用。

  1. ✅ 小麥輸入法
  2. ✅ 晶晶輸入法
  3. ✅ 唯音輸入法
  4. 狗哥智慧輸入法
  5. AquaType
  6. 靈犀注音
  7. ✅ 善解 shanjie - 來自 Thread 朋友推薦
  8. 千秋輸入法 - 網友留言推薦
  9. 洋蔥輸入法 - 來自 Thread 朋友推薦
  10. 通譯輸入法 - 來自 Thread，作者的推薦
  11. 超注音 - 來自 Thread 朋友推薦

1. 個人使用情境

  • 文章寫作，通常是長文 (5,000 字左右)
  • 跟 AI 對話，寫 Prompt
  • 中英文中間一定會加 space
  • 主要會在 Zed 做輸入
  • 盲打，雙手手掌不用移動為原則的配置
  • Macbook Pro

2. 個人習慣 + 個人會留意的

  • 候選字有沒出現「簡體字」
    • 正體輸入法大部分不會用到 簡體字
  • 建議詞會不會出現明顯的「怪詞」，macOS 的注音有很多怪詞
    • 習慣 -> 錫罐：沒用過、沒看過「錫罐」這個詞
    • 正體 -> 政體：不知道什麼「政體」，政治系的才會用，排在「正體」的前面。
  • 會不會記住個人慣例用詞，例如選過詞，會不會被記住、排序會不會自動調整？
    • 記得在 ET3 忘形就會記住了 XDD
    • 前面一段的「正體」已經打了四次了，我也重選四次了，但就是維持在「政體」，哪個輸入法我先不說。
  • 使用一段時間後 (約一個月)，整體的穩定性。
    • 遇過使用一段時間，反應越來越慢，感覺是出現記憶體管理問題
  • 常見用的全形標點符號，像是 “，”、”。”、”、”、”「”、”」” 位置改變與否？
    • 個人習慣 macOS 內建的配置，像是頓號、的配置，會影響輸入的流暢度。
  • 操作習慣參照 macOS 配置：
    • 選字: Space
    • 切換輸入法：Cap
  • 因為有多台 macOS 環境，原則上使用預設，以及少量配置 (少於三個)
  • 是否有任何鍵盤側錄行為
    • 作者背景，開發團隊背景

3. 長時間使用的體感

預設的配置下的體驗，底下是目前使用頻率排名：

  1. macos 注音: 依舊是主力、主要是習慣
  2. 小麥:
    • 體感上輕量，切換反應速度快
    • 基本操作 (選字 + 切換) 與 macOS 習慣一致
    • 常用的全行符號位置不一樣，需要重新熟悉
  3. 唯音:
    • 體感也是輕量，反應速度快
    • 基本操作 (選字 + 切換) 與 macOS 習慣一致
    • 常用的全行符號位置不一樣，需要重新熟悉
  4. 晶晶：
    • 不需要切換輸入法中英文輸入很酷
    • 體感稍重，反應速度沒有前三者快
    • 缺點：選字要按 「下」，手要在鍵盤上移動
    • 手速稍快的時候，有些字會不見 (miss input)

晶晶輸入法作者的建議

針對我個人使用的習慣與回報，作者 在 Thread 回覆我：

我實際做了以下設定：

  1. 調整選字行為：使用空白鍵
  2. 改用橫式選字窗：水平
  3. 吃字的部份，目前按照作者的建議調整如下：
    1. 注音優先模式：關
    2. 數字排列一律當注音：關
    3. 工程與程式用語：關
